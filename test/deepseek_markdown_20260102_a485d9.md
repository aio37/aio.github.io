# 中小企業向けコーポレートサイト

Bootstrap 5を使用したレスポンシブコーポレートサイトです。GitHub Pagesでそのままホスティングできます。

## 📋 特徴

- 5ページ構成（トップ、サービス、会社概要、実績、お問い合わせ）
- レスポンシブデザイン（モバイルファースト）
- モダンで信頼感のあるデザイン
- 青を基調としたカラーテーマ
- Bootstrap 5 + Font Awesome
